# Water Relay

Water Relay is a responsive, 45-second clean-water collection game built with
plain HTML, CSS, and JavaScript. It is inspired by charity: water’s mission and
does not use the organization’s official logo.

## Features

- Randomized yellow jerry cans worth 10 points
- Bonus golden cans worth 20 points
- Contaminated-water obstacles that subtract 10 points
- Live score, progress, feedback, and 45-second timer
- Win and loss states
- Reset and replay controls
- Confetti win celebration
- Personal best saved in the browser
- Touch, mouse, and keyboard support
- Responsive design and reduced-motion support

## Publish on GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the
   repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub to display the published URL. It will look like:
   `https://username.github.io/repository-name/`
7. Open that URL in a private browser window before submitting it.

No build command or package installation is required.
